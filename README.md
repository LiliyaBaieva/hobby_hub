# HobbyHub — Система управління позашкільною освітою 🚀

**HobbyHub** — це вебзастосунок на базі Django, розроблений для автоматизації обліку гуртків, викладачів та учнів. Проєкт реалізує повний цикл керування даними (CRUD) та має розмежовані права доступу для адміністраторів і відвідувачів.

---

## ✨ Основні можливості

* **Керування гуртками:** Візуалізація освітніх напрямків у вигляді карток із повною інформацією.
* **Реєстр викладачів:** Облік персоналу з деталізацією ПІБ та спеціалізації.
* **База учнів:** Централізована таблиця всіх учнів із прив'язкою до конкретних гуртків.
* **Система авторизації:** * *Адміністратор:* Має повний доступ до створення, редагування та видалення записів.
    * *Гість:* Має доступ лише для перегляду актуальної інформації.
* **Безпека:** Реалізовано захист від CSRF-атак та безпечний механізм виходу із системи (POST logout).

## 📦 Встановлення та запуск

Для запуску проєкту на локальній машині виконайте наступні кроки:

1. **Клонуйте [репозиторій](https://github.com/LiliyaBaieva/hobby_hub.git):**

   ```bash
   git clone https://github.com/LiliyaBaieva/hobby_hub.git

   cd hobby_hub
   
2. Створіть та активуйте віртуальне середовище:

    ```bash
    python -m venv venv
    # Для Windows:
    source venv/Scripts/activate

3. Встановіть необхідні залежності:

    ```bash
    pip install -r requirements.txt

4. Виконайте міграції бази даних:

    ```bash
    python manage.py migrate

5. Запустіть сервер:
    ```bash
    python manage.py runserver
